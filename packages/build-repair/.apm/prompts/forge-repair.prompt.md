---
description: Prepare a minimal repair from a failed check and its evidence.
---

Use the `forge-diagnose` and `tdd` skills on the supplied failure and candidate revision. Reproduce the symptom, patch the smallest responsible component, and run the same check again. Report commands and results. If you lack a reproducible failure or required permissions, report the blocker and the evidence collected. Keep acceptance criteria, tool configuration, and workflow permissions outside the patch.
